# Styling (frontend)
## Prinzipien
- **Individuell vor Framework:** Framework als Basis, Look & Feel projektspezifisch anpassen.
- **Design-Tokens:** Farben, Spacing, Typo zentral definieren.
- **Responsive:** Mobile-First; klare Breakpoints; konsistente Abstände.

## CSS-Regeln
- Keine magischen Zahlen; nutze Tokens/Variablen.
- Kein `!important`, außer als gezielte Ausnahme.
- Zustände (hover/focus/active) immer definieren.

## Checks
- [ ] Buttons/Links haben sichtbaren Focus.
- [ ] Kontrast AA erfüllt.
- [ ] Layout bricht nicht zwischen Breakpoints.
