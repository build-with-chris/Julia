# Best Practices (global)
## Performance
- Bilder komprimieren, moderne Formate nutzen; Lazy-Load für Media.
- JS/CSS minimieren; unnötige Abhängigkeiten vermeiden.

## SEO & A11y
- Semantisches HTML; sinnvolle Headings.
- `alt`-Texte, Fokusreihenfolge, ARIA-Labels.
- Sinnvolle `<title>` und Meta-Description pro Seite.

## Cross-Browser & Devices
- Test auf Chrome, Firefox, Safari, Edge.
- Mobile-First: gängige Viewports prüfen (375, 768, 1024, 1440).

## Deployment
- Staging vor Live.
- UTM-Links testen; 404/500-Seiten vorhanden.
